# RemoteIO Bundle Template
- Copy this folder to /home/pi on a target Pi.
- Run: ./install.sh

After install:
- http://localhost      (UI)
- http://<Pi-IP>/studio (Node-RED)
- Modbus TCP server on port 1502 (unit 1)

Edit api/server.js or modbus/modbus-server.js as needed.
